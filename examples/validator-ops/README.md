# Validator Ops Lab (Simulation)

This lab provides executable drills used by the Validator Ops Bootcamp.

## Quick start

```bash
cd examples/validator-ops
chmod +x scripts/*.sh
./scripts/init-lab.sh
./scripts/simulate-head-lag.sh
./scripts/simulate-double-signer.sh
./scripts/rollback-drill.sh
./scripts/verify-drill.sh
```

Artifacts are written to `artifacts/`.
